\# System Architecture



\## Overview



The Agentic Code Review Platform analyzes GitHub Pull Requests using

LLMs, repository-aware retrieval, specialized agents, code-analysis

tools, evidence verification, and automated evaluation.



\## High-Level Flow



GitHub Pull Request

&#x20;       ↓

GitHub Webhook

&#x20;       ↓

Backend API

&#x20;       ↓

Review Orchestrator

&#x20;       ↓

Specialized Review Agents

&#x20;       ↓

Repository RAG + Code Analysis Tools

&#x20;       ↓

Evidence Verification

&#x20;       ↓

Review Synthesizer

&#x20;       ↓

GitHub Review
